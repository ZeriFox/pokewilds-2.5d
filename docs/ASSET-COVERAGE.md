## Portable PNG encoding

The atlas and three PMD compatibility PNGs use `tools/deterministic_png.py`: RGBA8, filter 0, fixed 65535-byte stored DEFLATE blocks and standard CRC/Adler checksums. Encoding has no platform-compressor dependency; the containing JAR/ZIP supplies compression. All original RGBA pixels (including RGB under transparent pixels) are preserved. Provenance records both encoded-file and decoded-pixel hashes.

Atlas decoded RGBA SHA-256: `4a7b9725517cea4aade0ed4020cc2be67de935e4d6517bceeb101da4d048da38`. Encoder SHA-256: `fb6044da64082e548b4e28189d045a23c68894ab29659e2f2f7d380f8835ee6c`.

This replaced platform-dependent PNG optimization after Linux zlib 1.3 and Windows zlib-ng 1.3.1 produced different atlas/Suicune file bytes with identical RGBA. Byte determinism remains a required CI check. `python tools/test_deterministic_png.py` validates PNG chunks/CRCs, fixed stored blocks, a golden byte sequence, native decoding, transparent pixel preservation and unchanged real atlas pixels.

## Loading precedence and scope

`BwAssets` loads the generated Stardew atlas (which explicitly retains the landscape regions listed below), then trainer-only Unova regions, then optional custom overrides. Retained landscape artwork remains a declared temporary dependency; it is not represented as newly acquired Stardew art. The independent PMD Pokémon atlas remains unchanged.

Coverage means a material resolves with valid bounds, nonempty pixels and declared source. It does **not** mean every gameplay identity or scene has been visually verified. `objectName` and `terrainName` contain dynamic mapping; the runtime inventory below exercises exact source-evidenced identities and reports all unresolved cases.
